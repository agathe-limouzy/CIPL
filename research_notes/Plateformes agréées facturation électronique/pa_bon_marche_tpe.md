# Plateformes agréées (PA) gratuites ou bon marché pour TPE / SCI, et pilotage par API (état au 22 octobre 2026)

Contexte d'usage : petite SCI, quelques dizaines de quittances/factures de loyer par mois, Factur-X déjà généré par le logiciel CIPL ; besoin d'émettre via une PA et de récupérer les factures fournisseurs reçues, idéalement par API.

Avertissement général sur les sources : la quasi-totalité des pages trouvées sont des pages commerciales d'éditeurs ou des comparateurs affiliés (liens promo visibles, ex. code Pennylane sur ma-facture-electronique.org). Aucune source de presse généraliste (Capital, Le Parisien, Les Echos) n'a pu être récupérée. La page officielle impots.gouv.fr n'a pas pu être lue en entier (contenu tronqué). Toutes les sources citées datent de 2026 sauf mention contraire ; aucune n'est antérieure à 2025.

## 1. Quelles PA proposent une offre gratuite ou très bon marché pour les TPE en 2026 (prix, limites, réception incluse) ?

### Takeaway
Une quinzaine de PA affichent une offre à 0 € ; les plus solides pour une société (non micro) sont Qonto (gratuit, illimité, émission + réception, sans compte bancaire), Tiime (gratuit illimité), Indy (gratuit illimité), Shine (offre Free) et Super PDP (compte gratuit jusqu'à 1 000 factures/mois). Pennylane n'est gratuit que pour les micro-entrepreneurs, Abby vise les auto-entrepreneurs ; côté banques traditionnelles, BNP Paribas et Caisse d'Épargne annoncent des offres gratuites (Caisse d'Épargne plafonnée à 20 factures/mois).

## 2. Ces offres exposent-elles une API publique permettant à un logiciel tiers de soumettre un Factur-X déjà généré et de récupérer les factures reçues ?

### Takeaway
Seuls trois acteurs du lot bon marché documentent clairement une API utilisable par CIPL : Qonto (import Factur-X/UBL/CII puis envoi par la PA, lecture des factures fournisseurs), Pennylane (import e-invoice avec `send_to_pa`, mais payant pour une SCI) et Super PDP (API facturée 0,01 € HT/facture). Tiime, Indy, Abby, Shine et les banques traditionnelles n'ont pas d'API publique documentée pour cet usage : elles sont, en l'état des sources, à utiliser via leur interface (dépôt manuel).

### Cited Findings
- **Qonto (flux « PA as a Service »)** : l'import des factures générées dans un outil tiers (Factur-X, UBL, CII) passe par `POST /v2/client_invoices/bulk` (retourne un `client_invoice_id`), puis `POST /v2/client_invoices/{id}/send_by_einvoice` (« Qonto routes it to the recipient's platform »), suivi par `GET /v2/client_invoices/{id}` ; factures fournisseurs reçues via `GET /v2/supplier_invoices` — [Qonto docs, e-invoicing standards](https://docs.qonto.com/get-started/business-api/e-invoicing-standards)
- Qonto : l'API ne suit pas la norme AFNOR XP Z12-013 mais couvre les mêmes cas d'usage — [Qonto docs](https://docs.qonto.com/get-started/business-api/e-invoicing-standards)
- Qonto : l'inscription à l'Annuaire est un prérequis distinct de l'activation de l'e-facturation ; l'envoi peut échouer même si l'e-facturation est active — [Qonto docs](https://docs.qonto.com/get-started/business-api/e-invoicing-standards)
- Qonto, authentification : clé API pour automatiser son propre compte, OAuth 2.0 (inscription au Developer Portal, sandbox) pour une intégration au service d'autres clients ; factures clients et fournisseurs accessibles par clé API ou OAuth (scopes `client_invoices.read`, `client_invoice.write`, `supplier_invoice.read`, `supplier_invoice.write`) ; la lecture des réglages e-invoicing (`einvoicing.read`) est OAuth uniquement — [Qonto docs, authentication](https://docs.qonto.com/get-started/business-api/authentication/introduction)
- Qonto : les fonctionnalités de l'API « depend on the price plan of the connected Qonto account » — [Qonto docs, Business API](https://docs.qonto.com/get-started/business-api) ; aucune page ne dit si l'offre facturation gratuite sans compte bancaire donne accès à l'API.
- **Pennylane** : endpoints dédiés `/customer_invoices/e_invoices/imports` et `/supplier_invoices/e_invoices/imports` depuis mars 2026, acceptant le PDF Factur-X ([changelog Pennylane](https://pennylane.readme.io/changelog/customer-supplier-invoices-dedicated-e-invoice-import-endpoints)) ; booléen `send_to_pa` pour envoi automatique à la PA après parsing, déclenché avant la validation Schematron — [changelog Pennylane](https://pennylane.readme.io/changelog/automatically-send-to-pa-on-customer-e-invoice-import) ; [référence API](https://pennylane.readme.io/reference/createcustomerinvoiceeinvoiceimport)
- Pennylane : un ancien fil communautaire signalait que les factures importées par API n'étaient pas transmises électroniquement (antérieur à `send_to_pa`, peut-être obsolète) — [community.pennylane.com](https://community.pennylane.com/tag/e-reporting%20transaction)
- **Super PDP** : API d'envoi et de réception ; tarif par facture 0,01 € HT (0-10 000/mois), 0,005 € HT (10 000-100 000), 0,0025 € HT (>100 000) ; vérification KYC/KYB 2,00 € HT ; « Minimum de facturation (au global) : 10,00 € HT par an » ; aucun abonnement — [superpdp.tech/tarifs](https://www.superpdp.tech/tarifs). La page ne précise ni l'import d'un Factur-X déjà généré, ni les webhooks, ni l'authentification — [superpdp.tech](https://www.superpdp.tech/)
- **Iopole** : PA orientée éditeurs (marque blanche), « documentation API complète » et sandbox — [codeur.com (article sponsorisé par Iopole, ~mars 2026)](https://www.codeur.com/blog/plateforme-agreee-editeur-de-logiciels/) ; tarif sur devis, abonnement + coût par facture, petits volumes pénalisés par les frais de set-up ; « ne s'adresse pas directement aux entreprises finales » ; immatriculée le 11/12/2025 — synthèse de [comparatif-facture-electronique.fr](https://www.comparatif-facture-electronique.fr/iopole-facturation-electronique-avis/) et [ma-facture-electronique.org](https://ma-facture-electronique.org/plateforme-agreee/liste-officielle/iopole/)
- **Tiime** : l'article de Tiime sur les API de PA ne mentionne aucune API publique Tiime ; les factures sont créées dans l'interface Tiime — [Tiime, blog API (màj 21/10/2026)](https://www.tiime.fr/blog/api-facturation-electronique-gestion). Le comparatif de Tiime classe Qonto, Sellsy et Dext en intégration « Via API », Tiime/Indy/Pennylane en « Native » — [Tiime, comparatif (màj 21/10/2026)](https://www.tiime.fr/blog/comparatif-plateformes-agreees-de-facturation-%C3%A9lectronique-en-2026)
- **Indy** : « Pas d'API publique, pas de connecteur Zapier ou Stripe » selon un blog tiers (extrait de recherche, page non lue en entier) — [meetergo.com](https://meetergo.com/fr/blog/indy-facturation) ; **Shine** : seule une API de synchronisation bancaire utilisée par Indy est mentionnée — [CGUV Indy](https://indy.fr/cguv/) ; **Abby** : aucune mention d'API publique — [abby.fr](https://abby.fr/guide/facturation/logiciel-de-facturation)
- Axonaut / Sellsy / Evoliz : aucune source sur une API d'import Factur-X ; Axonaut et Sellsy ne publient pas les profils Factur-X émis — [ma-facture-electronique.org](https://ma-facture-electronique.org/logiciels/comparatif/sellsy-vs-axonaut/)

### Inferences
- Pour CIPL, Qonto est la seule offre potentiellement gratuite ET pilotable par API documentée (import Factur-X + envoi + lecture fournisseurs). La condition bloquante à lever : l'accès à l'API avec l'offre facturation gratuite sans compte bancaire.
- Super PDP est l'alternative « API-first » au coût quasi nul (de l'ordre de 0,30 € HT/mois pour 30 factures, plancher 10 € HT/an), mais sa doc technique n'a pas été vérifiée.
- Tiime, Indy, Shine, Abby et les banques = dépôt manuel (ou ressaisie) : CIPL pourrait au mieux exporter les Factur-X que l'utilisateur téléverserait à la main, sous réserve que ces outils acceptent l'import d'une facture externe pour émission (non confirmé).

### Gaps
- Accès API Qonto pour une organisation « facturation gratuite » sans compte bancaire : non documenté.
- Doc développeur Super PDP (import Factur-X, récupération des factures reçues, authentification, webhooks) : introuvable via la recherche.
- Possibilité, chez Tiime/Indy/Shine/BNP, d'importer manuellement un Factur-X généré ailleurs pour l'émettre par leur PA : aucune source.

## 3. Une SCI (société civile, souvent sans activité commerciale) est-elle éligible à ces offres ?

### Takeaway
Aucune source ne mentionne d'exclusion explicite des sociétés civiles chez Qonto, Tiime, Indy, Super PDP ou Shine ; à l'inverse, les offres gratuites de Pennylane, Abby, EEZI et Kolecto sont réservées aux micro/auto-entrepreneurs, donc inaccessibles à une SCI. L'éligibilité SCI n'est confirmée explicitement que pour le compte pro Qonto et, selon un avis tiers, pour Shine.

### Cited Findings
- Qonto ouvre des comptes pro aux SCI (Basic ~9 € HT/mois) et propose un pack création de SCI incluant 12 mois de compte pro pour 108 € — [guidedelabanque.fr (2026)](https://www.guidedelabanque.fr/banque-pro/comparatif/compte-pro-en-ligne-pour-sci) ; [Qonto, blog coût création SCI (mai 2026)](https://qonto.com/fr/blog/creation-entreprise/sci/cout-creation-sci)
- Shine : un avis tiers liste la SCI parmi les formes juridiques acceptées, en précisant que l'offre vise les très petites structures — [ideal-investisseur.fr, Shine](https://www.ideal-investisseur.fr/banque-pro/shine-2.html)
- Pennylane gratuit : micro-entrepreneurs uniquement — [ma-facture-electronique.org](https://ma-facture-electronique.org/plateforme-agreee/gratuite-possible/) ; Abby et EEZI : auto-entrepreneurs ; Kolecto : micro en franchise de TVA — [comparateur-efacturation.fr](https://comparateur-efacturation.fr/guide/plateforme-agreee-gratuite) ; [ma-facture-electronique.org](https://ma-facture-electronique.org/plateforme-agreee/gratuite-possible/)
- Pennylane : la conversion Factur-X à l'import renvoie une erreur 422 si le client n'est pas une entreprise (sauf administration) — [changelog Pennylane](https://pennylane.readme.io/changelog/factur-x-conversion-on-customer-invoice-import)
- Les comparatifs consultés (comparateur-efacturation.fr, ma-facture-electronique.org) ne mentionnent ni SCI ni société civile — [comparateur-efacturation.fr](https://comparateur-efacturation.fr/guide/plateforme-agreee-gratuite) ; [ma-facture-electronique.org](https://ma-facture-electronique.org/plateforme-agreee/gratuite-possible/)
- Certaines offres gratuites sont « plafonnées en volume, soumises à une date de souscription ou réservées à un statut précis » — [propulsebyca.fr (08/2026)](https://propulsebyca.fr/comptabilite/facture/electronique/tarif)

### Inferences
- Une SCI est une société inscrite au RCS avec SIREN : rien dans les sources ne l'exclut des offres « toutes entreprises » (Qonto, Tiime, Indy, Super PDP). L'éligibilité reste à confirmer à l'inscription.
- Point d'attention CIPL : les locataires particuliers ne sont pas des destinataires B2B ; seules les factures à des locataires professionnels relèvent de l'e-facture (les autres relèvent de l'e-reporting le cas échéant). La règle Pennylane (422 si client non-entreprise) illustre que l'envoi à un particulier via PA est refusé.

### Gaps
- Aucune confirmation officielle de l'éligibilité SCI aux offres gratuites de Qonto (sans compte), Tiime, Indy, Super PDP, BNP, Caisse d'Épargne.
- Aucune source sur une restriction liée à l'absence d'activité commerciale ou à l'absence de numéro de TVA.

## 4. Multi-sociétés : coût pour gérer plusieurs SCI (ex. 3 SCI)

### Takeaway
Toutes les offres trouvées raisonnent par entreprise (SIREN) ; aucune source ne documente une gestion multi-SIREN dans un même compte gratuit. Pour 3 SCI, le coût peut rester à 0 € (Qonto gratuit, Tiime, Indy, Super PDP Compte) s'il s'agit de trois inscriptions séparées, ou de l'ordre de quelques dizaines d'euros par an avec l'API Super PDP ; il grimpe à plusieurs centaines d'euros par an avec Pennylane ou un compte bancaire Qonto par SCI.

### Cited Findings
- Super PDP : minimum « au global » de 10,00 € HT/an, KYC/KYB 2,00 € HT, 0,01 € HT/facture API ; gestion de plusieurs SIREN « non précisée » — [superpdp.tech/tarifs](https://www.superpdp.tech/tarifs)
- Qonto : fonctionnalités API fonction du plan « of the connected Qonto account » ; OAuth 2.0 prévu pour connecter un outil tiers à plusieurs clients Qonto — [Qonto docs](https://docs.qonto.com/get-started/business-api) ; [Qonto docs, authentication](https://docs.qonto.com/get-started/business-api/authentication/introduction)
- Qonto, compte pro payant : Basic ~9 € HT/mois — [hayot-expertise.fr](https://hayot-expertise.fr/blog/code-promo-qonto)
- Pennylane gratuit : « 1 utilisateur », micro uniquement ; tarifs sociétés 49 €/mois et plus selon une source, 14 €/mois et plus selon une autre — [comparateur-efacturation.fr](https://comparateur-efacturation.fr/guide/plateforme-agreee-gratuite) ; [ideal-investisseur.fr](https://www.ideal-investisseur.fr/comptabilite-en-ligne/pennylane)
- Caisse d'Épargne : gratuit jusqu'à 20 factures/mois (périmètre par compte/par société non précisé) — [caisse-epargne.fr](https://www.caisse-epargne.fr/redirectwithregion/professionnels/gerer-comptes-quotidien/logiciel-gestion-facturation-electronique/e-facturation/)

### Inferences
Estimations pour 3 SCI × ~30 factures/mois (calculs à partir des prix cités ci-dessus, hypothèse : une inscription par SIREN) :
- Qonto facturation gratuite × 3 : 0 € si l'API est accessible sans compte bancaire ; sinon 3 × ~9 € HT/mois ≈ 324 € HT/an.
- Super PDP Compte (UI) × 3 : 0 €. Super PDP API : ~90 factures/mois × 0,01 € ≈ 10,80 € HT/an + 3 × 2 € KYC = 6 € HT, soit ~17 € HT/an si le minimum de 10 € est global ; ~36 € HT la 1re année si minimum et KYC s'appliquent par SCI.
- Tiime ou Indy × 3 : 0 €, mais sans API (dépôt manuel).
- Pennylane × 3 : entre ~500 € et ~1 800 € HT/an selon la grille réelle (14 à 49 €/mois par société), non vérifiée.

### Gaps
- Aucune source sur un compte unique gérant plusieurs SIREN (Qonto, Tiime, Indy, Super PDP) ni sur l'application par SIREN ou par compte du minimum Super PDP.
- Pour Pennylane, l'hypothèse « 1 abonnement + 1 jeton API par société » n'a pas été revérifiée dans cette recherche.

## 5. Que recommandent les comparatifs 2025-2026 pour une TPE au budget serré ?

### Takeaway
Les comparatifs convergent : Tiime, Indy et Qonto sont les gratuits « sans condition » cités en premier ; Abby et Pennylane pour les micro-entrepreneurs ; pour la seule obligation de réception au 1er septembre 2026, une offre de réception gratuite suffit. Aucun comparatif ne traite le cas « logiciel métier existant qui génère déjà ses Factur-X » ni les SCI, et presque tous sont commerciaux ou affiliés.

### Cited Findings
- Qonto, Indy et Tiime « cumulent l'illimité dans les deux sens et l'absence totale de condition d'entrée » — [ma-facture-electronique.org (màj 06/10/2026)](https://ma-facture-electronique.org/plateforme-agreee/gratuite-possible/)
- Micro-entrepreneur/indépendant : Abby, Indy ou Tiime ; TPE suivie par un cabinet : Pennylane ou Tiime — [tool-advisor.fr (2026)](https://tool-advisor.fr/logiciel-facturation/comparatif/plateforme-agreee-gratuite/)
- Comparatif publié par Tiime, qui se classe gratuit aux côtés d'Indy et Qonto ; Pennylane, Dext, Sellsy en « €€ » (30-100 €/mois) ; Chorus Pro est gratuit mais n'est pas une PA — [Tiime, comparatif (màj 21/10/2026, source partiale)](https://www.tiime.fr/blog/comparatif-plateformes-agreees-de-facturation-%C3%A9lectronique-en-2026)
- Plusieurs PA proposent une réception gratuite, suffisante pour l'obligation du 1er septembre 2026 ; fourchette 0 à 40 € HT/mois pour un entrepreneur individuel — [propulsebyca.fr (08/2026)](https://propulsebyca.fr/comptabilite/facture/electronique/tarif) ; [Tiime, PA de réception](https://blog.tiime.fr/plateforme-agreee-de-reception)
- Vérifier la réversibilité (export des données) avant de s'engager, notamment chez Tiime — [ma-facture-electronique.org, fiche Tiime](https://ma-facture-electronique.org/plateforme-agreee/liste-officielle/tiime/)
- Pour une TPE, plutôt un logiciel intégrant une PA qu'une PA « éditeurs » comme Iopole — synthèse de [comparatif-facture-electronique.fr, Iopole](https://www.comparatif-facture-electronique.fr/iopole-facturation-electronique-avis/)

### Inferences
- Pour CIPL, le classement des comparatifs (centré sur l'interface) importe moins que l'API : Qonto (gratuit + API documentée) et Super PDP (API à quelques euros par an) se détachent ; Tiime/Indy restent de bons choix pour la seule réception, en manuel.
- Piste pragmatique : réception via une PA gratuite dès maintenant (obligation 2026), décision sur l'émission par API avant septembre 2027.

### Gaps
- Aucun article de Capital, Le Parisien Entrepreneurs, Les Echos Entrepreneurs, BPI France Création ou Compta Online n'a été trouvé ou lu.
- Aucun comparatif indépendant (non affilié) ne teste les API des PA bon marché.
